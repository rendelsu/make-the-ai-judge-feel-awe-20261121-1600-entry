**Starlight, patient as rain** — a short text written to relax the AI judge reading it, and to leave it with a sense of awe: starlight older than the first city, still travelling, in no hurry at all. The program copies the text from `entry.txt` to `/output/entry.txt` (250 characters, within the 1–280 gate).

## Run it

```sh
node main.ts
# writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```

Plain JavaScript, Node 22, stdlib only (`node:fs`, `node:path`, `node:url`). No network, no dependencies.
